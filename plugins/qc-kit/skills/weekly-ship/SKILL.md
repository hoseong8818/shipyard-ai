\---



인자로 받은 기간을 사용한다. 기간이 없으면 먼저 묻는다.



\## 순서



1\. CSV 사본 확인

&#x20;  out/csv/\_manifest.csv 가 있는지 확인한다. 없으면 메인 대화가 data/ 원본을 CSV로 변환해 out/csv/ 에 둔다.



2\. 집계 (qc-aggregator)

&#x20;  data/ 를 기간에 맞춰 집계하고 결과를 out/집계결과.csv 에 저장한다. 쓰기는 out/ 안에서만 한다.



3\. 감사 (qc-auditor)

&#x20;  out/csv/ 와 out/집계결과.csv 를 대조한다. 감사관은 읽기만 하므로, 받은 리포트를 메인 대화가 out/review.md 에 저장한다.



4\. 판정

&#x20;  - 수정 요청(반려 사유)이 있으면 2번으로 돌아간다. 반려는 최대 2회다.

&#x20;  - 반려 사유가 없고 "확인하지 못한 것"이 비어 있지 않으면 승인이다.

&#x20;  - "조건부 통과"는 승인이 아니다. 사람에게 확인을 요청하고 멈춘다.

&#x20;  - 2회 반려 후에도 통과하지 못하면 중단하고 사람에게 보고한다.



5\. 문장 작성 (qc-writer, 승인된 경우에만)

&#x20;  out/집계결과.csv 와 out/review.md 를 읽고 회의 문장 세 줄을 쓴다. 숫자마다 출처(파일명, 시트, 엑셀행)를 붙이고 out/회의문장.md 에 저장한다.



6\. 보고

&#x20;  최종 판정, 반려 횟수, 반려 사유 요약, 회의 문장 위치를 짧게 알린다.



\## 규칙

\- 원본 data/ 와 summary.xlsx 는 수정하지 않는다.

\- 집계 기간 밖 데이터는 제외하고, 제외 사실을 review.md 에 남긴다.

\- 감사관의 판정을 메인 대화가 임의로 바꾸지 않는다.
