# qna-helper

사내 기술 QnA 게시판(도면, 공정, 품질, 안전 절차)을 Claude Code에서 검색해 답하는 플러그인입니다.

## 구성

- `server/qna-mcp.js`: 게시판 검색 MCP 서버 (`search_questions`, `get_question`). 외부 패키지 없이 Node.js만 씁니다.
- `skills/ask/SKILL.md`: 답하는 규칙. 게시판 내용만 근거로 답하고, 채택되지 않은 답변은 그렇다고 밝히며, 끝에 질문 번호, 제목, 링크를 붙입니다. 없으면 지어내지 않고 찾아본 검색어와 함께 게시판에 질문을 올리라고 안내합니다.

## 설치

```text
/plugin install qna-helper@<마켓플레이스 이름>
```

설치할 때 게시판 주소(`qna_api`)를 입력합니다. 나중에 바꾸려면 `/plugin configure`를 씁니다.

## 사용

"선미 블록 개정 도면은 언제 반영돼?"처럼 물어봅니다. 스킬 실행을 묻는 창에서는 Yes를 누릅니다.

## 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "게시판 조회 실패" | 게시판 주소와 서버가 켜져 있는지 |
| 검색 결과가 늘 0건 | 검색어가 너무 깁니다. 핵심 용어 1~3개로 줄입니다 |
